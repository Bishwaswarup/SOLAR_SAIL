─── 544 m/s figure ─────────────────────────────────────────────────────────
  A true heteroclinic connection costs ZERO dV by construction.  544 m/s with a
  57 km residual is a manifold-guided two-impulse transfer, not a heteroclinic
  connection.  It was also computed at Az = 0.02 for both halos, so its L2
  endpoint was the spurious orbit above.  fig6 and fig7 are INVALIDATED and
  must be regenerated at a matched pair with the self-intersection guard.

─── Root cause of the branch-hopping ───────────────────────────────────────
  compute_halo_orbit free variables:  [x0, vy0, T_half]
  constraints:                        [vx_f, vz_f, y_f] = 0
  z0 is never a free variable and Az is never a constraint.  Az only seeds the
  Richardson guess, and passing x0 replaces z0 entirely (making Az a no-op).
  Fix applied in jacobi_match.py: continue (x0, vy0) but overwrite z0 with the
  requested Az each step, plus a period-continuity branch guard.
  Proper fix: add z0 as a free variable with an amplitude constraint.

─── Sail force model ───────────────────────────────────────────────────────
  dynamics.py implements the IDEAL SPECULAR REFLECTOR correctly:
      a = beta (1-mu)/r1^2 * cos^2(alpha) * n_hat        (purely normal)
  An earlier README draft wrote the PERFECT ABSORBER form
      a = beta (1-mu)/r1^2 * cos(alpha) * [cos(alpha) n_hat + sin(alpha) t_hat]
  which is force along the sun-line with magnitude ~ cos(alpha).  They agree
  only at alpha = 0.  The code was right; the documentation was wrong.
  Figures 4 and 5 are unaffected.
